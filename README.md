# 生成AIパスポート学習ドリル

2026年2月〜10月試験の公式シラバス（旧シラバス）を学習範囲として作成した、非公式のオリジナル問題集です。

- オリジナル問題158問（うち難問60問：事例判断・紛らわしい選択肢、選択肢ごとの解説つき）
- 5分トレーニング
- 章別演習
- 60問・60分の模擬試験（通常／難問）。一時停止・再開でき、アプリを閉じても続きから再開可能
- 誤答復習
- 端末内への進捗保存
- オフライン対応
- パソコンの広い画面では、解説を問題の右に表示しキーボード（1〜4・A〜D・Enter）で操作可能

公式問題の転載・復元ではありません。合格を保証する教材ではなく、85%は本教材独自の学習目標です。

学習サイトはGitHub Pagesで公開しています。
